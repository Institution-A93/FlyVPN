# docs

Документация проекта, не привязанная к конкретному компоненту.

- [`adr/`](./adr/readme.md) — Architecture Decision Records: зафиксированные технические решения с контекстом и обоснованием.
- [`architecture/`](./architecture/readme.md) — визуальные схемы (Graphviz): построенное и целевое.
- [`research/`](./research/readme.md) — разведка и спайки перед фиксацией ADR (сравнения, аудит).
- [`backend-requirements.md`](./backend-requirements.md) — спека бэкенда (draft v3, в части entitlement — через призму ADR-0021).
- [`backlog.md`](./backlog.md) — пост-MMVP идеи и открытые вопросы (созревшие — переходят в ADR).

Полная тех-спецификация продукта — в корневом [`README.md`](../README.md).
